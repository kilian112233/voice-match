I have been building a homelab for the past week, and Docker has made it far simpler than I expected. You start one container and the service is running; there is no real setup beyond the compose file. Jellyfin, Nextcloud, and a few game servers now run on my old gaming PC. Hosting everything myself removes the need to pay for cloud storage, and my files stay on hardware I control. Given a weekend, I can set up almost any service from scratch. Port forwarding remains the only part I still find awkward.
